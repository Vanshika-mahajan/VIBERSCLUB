# ADR-0013: Opt-in women-only discovery

- **Status:** Accepted, pending user validation
- **Date:** 2026-10-25
- **Deciders:** ARPIT

## Context
Travel-companion matching carries specific safety concerns for women travellers.

## Decision
Users who identify as women can switch on "Discover and be discovered by women only". It filters both directions in eligibility rules. Gender is optional profile data, used only for this filter and never shown unless the user chooses to.

## Consequences
- Gender is self-declared; misuse is handled through reports.
- Validate the design in interviews with at least five women who travel solo before building.
