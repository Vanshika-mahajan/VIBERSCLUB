# ADR-0012: 18+ only

- **Status:** Proposed
- **Date:** 2026-10-25

## Context
The app connects strangers for travel and nightlife. India's DPDP Act requires verifiable parental consent to process children's data (under 18).

## Decision
Users confirm date of birth at signup; under-18s cannot create an account. Events may set a higher minimum age (for example nightlife events), shown on the event and confirmed at RSVP.

## Consequences
Legal minimum ages for alcohol-related events in Himachal Pradesh must be confirmed by a lawyer before launch.
